## 🧩 Problem-Solving Approach

For every problem, I try to follow this process:

1. Understand the problem
2. Identify the pattern
3. Think of a brute-force solution
4. Optimize the approach
5. Analyze time complexity
6. Analyze space complexity
7. Implement the solution
8. Test with edge cases
9. Refactor if necessary

---

## 📝 Solution Format

Each solution focuses on:

```text
Problem
    ↓
Understanding
    ↓
Approach
    ↓
Implementation
    ↓
Time Complexity
    ↓
Space Complexity
```

Example:

```python
def count_digits(n):
    count = 0

    while n > 0:
        n //= 10
        count += 1

    return count
```

**Time Complexity:** `O(log n)`

**Space Complexity:** `O(1)`
